The implementation is
`scripts/independent_round_trip_population_runtime_development.py`. It connects
the fixed original collector and raw auditor to the previously verified case-
evidence layer. It binds collection bytes before audit, closes and binds logs,
records process identities and authenticates worker and parent completion files.

pool to close before advancing, rechecks the whole remaining resource allowance
and native-process guard, retains scientific failures, and stops on incomplete
collection/audit or infrastructure failure. It never retries or resumes.

identity uniqueness. It authenticates each completed fixed startup reference

artifact identities and traceback. A worker failure receipt vetoes completion
even if a terminal file was written before a later persistence error. Parent
errors preserve the exact completed prefix, active case and stage. A filename-
only root check refuses any existing partial or orphan artifact without opening
unexpected contents. The final full-population readout uses the existing
32-case/eight-unit accounting and keeps qualification flags false.
