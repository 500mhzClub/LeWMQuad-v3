# Contact-plus-flow native prefix comparison V1

This helper admits a completed recovered full-controller replay and compares
a future native episode with it. It starts no execution. The full-controller
owner must have ended, and its exact launch hash, source closure, result and
artifact roster must verify. Reconstruct the original ended-worker admission,
all 562 saved comparisons against the original raw decisions and fixed
observer evidence, and every actual public-packet fingerprint.

The report must retain 561 unchanged earlier candidate decisions and 558
preboundary forecast comparisons, exact original model state, two fresh model
copies, no postboundary recorded observations, and full controller recovery
at frame 561. Check the selected action against the fixed command bank and
the reported changed-command flag. Negative controller outcomes are retained
as evidence but do not pass this native-admission helper.

The future native comparison requires every original and candidate command
through frame 561 to complete with its exact physical sample endpoints. All
earlier commands must match; the original boundary request is hold and the
candidate boundary request must match the completed replay. The candidate can
also select hold. In that case the observation/controller recovery is the
intervention and the command is explicitly unchanged.

Require all raw physics fields to match over the first 28,800 samples, plus
all 562 raw public observations and complete candidate decisions. Require
at least 28,850 physical samples in each trace so the 50 samples of the
boundary command are present; a command-tape completion flag alone is not
sufficient. Do not require subsequent physics to match the old trajectory.
Future outcomes come only from the fresh measured run and its full audit.

Original and candidate sensor packets use the exact public fingerprint order
`(policy, primary_depth, fast_gyro, auxiliary_rgb, auxiliary_depth)`, matching
the completed observer and current controller replay. Private native state
is used solely for the post-run physical comparison, never for commands.

A future native launcher still needs the original model/input chain, original
queue completion, resource admission and an exclusive idle native scene.
This helper does not select a policy or claim navigation, real-time or hardware
qualification. Preserve already frozen or queued experiments unchanged.
