# Moving-action switch collection scaling V1

Freeze all new collector, auditor, accounting, benchmark, scientific runner and
focused test sources by the benchmark launch manifest before any new native
episode. Preserve inherited sources and sealed custody. This is one exclusive
infrastructure measurement, with no retry, continuation or benchmark-data reuse.

Use exactly four fixed cases: a one-second left-arc prefix followed by the full
four-second hold plan on each of clusters 00, 01, 02 and 03 in the canonical
left-open appearance-2026090940 specification. Run all four sequentially, then
the same four with four concurrent fresh CPU processes. Each child owns exactly
one episode; OpenCV/BLAS threads are one. CPU physics, frozen gait/actuator,
ordered union RGB/depth and all original physical stops are unchanged.

Require all four cases in each phase to have the complete 63-command,
64-frame, 3,900-physics-sample schedule, all raw command/sensor/stop replays,
strict physical visibility and stable-interior/near-occlusion checks. Stop
before a second phase if the first fails. No tolerance replaces a failed exact
comparison. Compare every saved NPZ array and all RGB pixel hashes across the
paired phases. ZIP timestamps and compute wall times are not identity fields.

Select four scientific workers only if both phases pass, all paired signatures
are exactly equal and measured full-phase speedup is at least 1.25. Otherwise a
passing serial phase selects one worker. Preserve failed phase receipts; an
incomplete benchmark grants no scientific launch.

Assess CPU/RAM/GPU/storage and competing jobs before launch. Require 32 GiB
available RAM and a 2-GiB benchmark allowance above the 40-GiB artifact reserve.
Monitor resources during each phase. Record the largest complete measured
episode artifact size. Scientific storage estimate is 144 times that size with
25 percent additional allowance, plus 512 MiB for cohort receipts; it must fit
the separately fixed 24-GiB scientific allowance before collection. Each worker
and each decision also checks the remaining reserve. This estimate is an
engineering allowance, not a proven maximum over all future images.

Roots: `go2_moving_action_switch_scaling_v1_attempt_001`,
`go2_moving_action_switch_scaling_serial_v1_attempt_001` and
`go2_moving_action_switch_scaling_four_v1_attempt_001`, under the existing owned

paired comparisons, measured throughput, byte estimate and selected workers.
No model training, closed-loop navigation or real-time qualification occurs.
