# Bounded factory startup with CPU instrumentation

Run the exact existing four-arm startup body on the same four saved packets
per arm, under the prepared CPU monitor. The reference is the completed
independent adapter factory startup result
`cd0af02bdbe978e714e55c1c0253f1fa01df88c4554eeea887deae84e40ae6db`.
Authenticate its sources, five outputs, original raw inputs and bound model
admission before and after execution. No new layout observations or commands
are permitted.

The process must start with `OPENCV_OPENCL_RUNTIME=disabled`, all three BLAS
thread environment values set to 1 and `PYTHONHASHSEED=0`. OpenCL must actually
report disabled. The original startup function code is reused with an isolated
globals dictionary changing only its output root. Imported module globals,
factory implementations, model identities and source receipts remain intact.

Each monitored scope includes original and adapted model reloads, controller
construction, four public observations, model verification and original
forward-output comparisons. Complete output reports and all four saved
decision rows must equal the original completed startup exactly. The reactive
arm remains model-free and may have no PyTorch operations. Each scope's monitor
receipt is retained even if the scope fails; all failures are terminal for this
attempt and no retry/resume is permitted.

The fixed study public mission is instantiated as in the reference. Packets
are from an already completed development startup, not an independent layout.
No packet after the first planning request is consumed and no requested
command is executed. The reference's deliberately incompatible original
factory failures remain part of the comparison.

Successful completion would show this bounded real factory/controller path
retains its outputs under explicit CPU instrumentation. It would not qualify
the complete raw auditor, prove OS device isolation, establish overlap speedup,
or permit independent study execution. Complete-auditor integration and actual
source-bound overlap qualification remain separate work.
