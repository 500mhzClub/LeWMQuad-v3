## Claim boundary

This result concerns `H1_ANY_PHYSICS_STEP_DISALLOWED_CONTACT` in the existing
Genesis maze and the authority of the frozen twelve-action bank over command
prefixes of 0.1--0.5 s. It does not establish material-impact safety, injury or
property-damage prevention, physical Go2 braking performance, human safety, or
closed-loop navigation safety. Shorter commitment is not an emergency brake,
and repeated replanning is not a substitute for a qualified fail-safe.

## Command and replanning contract

- Genesis physics step: 2 ms.
- Low-level locomotion-policy step: 20 ms.
- High-level command tick: 100 ms.
- Current route block: five command ticks, 0.5 s total.
- Current MPC loop renders/scores once, selects the first primitive, and then
  executes the complete five-tick clipped block.
- The low-level runner can accept a different target every 100 ms, and a
  development capture path can render every command tick.
- The production path does not construct a complete planner/predictor input or
  invoke the predictor every 100 ms. No render-plus-predictor deadline or
  one-tick preemption latency has been qualified.

Accordingly, the minimum *demonstrated system commitment* remains five ticks.
The controller seam suggests a possible one-tick implementation, but the
minimum technically achieved end-to-end commitment is
`REPLANNING_INTERFACE_UNRESOLVED`, not `ONE_TICK_REPLANNING_AVAILABLE`.

## Decision

Primary classification: `ONE_TICK_SAFE_ACTION_SET_NO_GO`.

The 0.5-second commitment contributes to the safe-action failure, because five
of eleven five-tick failures recover in shorter trace prefixes. It is not the
principal sufficient explanation: six states remain without any safe action
even at 100 ms. Faster replanning alone therefore cannot establish the required
recoverable action envelope.

Scientific planner work cannot yet proceed conditionally to
`SHORT_COMMITMENT_RECEDING_HORIZON_PLANNER_V1`. The next bounded implementation
requirement is:

`STRICTER_STATE_ELIGIBILITY_AND_ONE_TICK_RESPONSE_ENVELOPE_REQUIRED`

It must prevent entry into states without a one-tick contact-negative response.
Separately, the observation, predictor, and command-replacement path must be
implemented and latency-qualified at 100 ms before the shorter-prefix planner
can be evaluated. Learned safety prediction remains blocked, and no sport-mode
adapter is authorised by this result.

The platform stopping-mode parity track remains pending. It requires physical
Go2 access or vendor parity traces, request/acknowledgement timing, high-rate
low-state and independently measured body-motion telemetry, IMU, motor
position/velocity/estimated torque, foot force, applied command, and
obstacle-free StopMove/BalanceStand/Damp trials. If that evidence is
unavailable, the track remains deferred.
