# From repeatable moving observations to independent-layout JEPA evidence

The moving pilot now provides exact candidate-action prefixes and bit-identical
repeated recorded streams, including real terminal contacts. It also preserves
strict silhouette-depth failures and the failed all-command-completion criterion.
Do not refit on the pilot, reinterpret its frozen result, or declare navigation
success. Its value is identifying a usable acquisition mechanism and the remaining
measurement/accounting work before a fresh independent-layout collection.

## 1. Implement a prospective acquisition-coverage contract

Separate data completeness from task success. Classify complete scheduled traces,
fully recorded physical-terminal traces, infrastructure-truncated traces, failed
setups and unattempted cases explicitly. A physical collision can end a valid
hazard observation without completing its command schedule. Require raw native
contact attribution, exact terminal sample, all pre-terminal sensor packets and
commands, no post-stop motion, and correct event/motion/future-image censoring.
Do not turn absent post-stop motion into zero motion or late images into targets.
Do not treat a pre-departure failure as an observed candidate-action outcome.

Test this contract synthetically against missing terminal samples, truncated
contact arrays, missing captures, fabricated post-stop samples, changed requested
commands, unavailable common prefixes and differing termination reasons. Preserve
the full planned denominator and physical/infrastructure failures by context.
Do not require collision examples to complete a command schedule after contact.

## 2. Establish finite-pixel measurement and sensor uncertainty semantics

Retain the original strict 1mm centre-ray score. Prospectively distinguish stable
interior evidence from pixel footprints crossing any foreground silhouette, and
report coverage and residuals for both. Native 8-bit subpixel rasterization is
consistent with the observed 0.000441-pixel edge case, but bit count alone is not
a proof that all boundary values are physically admissible. Keep below-near
occluders and false public-valid returns as failures, not discarded samples.

Prove the new measurement accounting on analytic thin-obstacle/foreground-edge/
near-plane counterexamples and a fixed native edge-crossing assay before adopting
it for new collection. A prospective assay must include perturbed views on both
sides of boundaries and interior-error negative controls, not only the known
failed pixel. No privileged evaluator geometry may become a policy input or a
pixel repair. Policy-side measured-depth boundaries and invalid ranges must remain
unknown/conservative; validate that a silhouette cannot become a false free-space
certificate for the articulated robot. RGB/body prediction eligibility and depth-
geometry navigation qualification are separate claims.

## 3. Collect the independent population once the contract is frozen

Use distinct collector/auditor/protocol/output paths with the fixed core-profile
readback and floor-first union rendering. Keep the existing 12-layout inventory
and 6/3/3 train/selection/development-evaluation roles; do not relabel the current
training layout as evaluation. Freeze exact sources, artifact rosters, storage
budgets, failure behavior and eligibility rules before fresh physics.

Collect all six candidate actions across quiet/recent histories, nominal/lower
friction and all five contexts. The pilot's two forward near-wall actions already
show different contact times from identical prefixes; the full action population
is necessary to identify safer alternatives, not merely predict unavoidable
collision. Retain unsafe initial conditions and acquisition failures rather than
selecting only favorable layouts or silently replacing cases. Audit each layout
to terminal before deciding to start the next bounded batch.

## 4. Test the actual scientific hypotheses

Execute the prepared matched direct/supervised-rollout/JEPA comparison with three
paired model seeds, identical train-only exposure, sensors, architecture budget,
auxiliary targets and cumulative-event semantics. Include action/time empirical
and zero-motion baselines, and RGB/history/action ablations. Report independent-
layout paired effects and contact timing/calibration, not correlated frame counts
or all-negative accuracy. Three model seeds are not three independent mazes.

Only demonstrated useful prediction should motivate the matched online-rollout
study. Reliable local stopping/turning, sensor-driven memory and executed
backtracking must then support whole novel-maze missions. The pilot's contacts
occur during braking, underscoring why a zero command is not proof of a stop.
Deployment-valid camera/IMU/proprioception, self-occlusion, latency/deadline tests,
and bounded supervised hardware evidence remain required. The ultimate goal is
unchanged and unachieved; no passing acquisition test substitutes for it.
