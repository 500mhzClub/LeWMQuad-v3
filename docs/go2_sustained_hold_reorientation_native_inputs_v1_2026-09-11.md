# Sustained native experiment input admission

This module joins the completed original raw sustained-turn prefix with the
completed original five-stage native queue. The raw replay owner and all queued
owners must have ended on the recorded boot before expensive admission begins.
No success threshold filters out a completed scientific failure.

The raw result and frozen launch are authenticated, the original raw input
admission is rerun, and the actual completion helper reconstructs the 407-row
prefix and current public packets. The original native hold result, original
assigned full-JEPA model and correction admission remain fixed.

The budget waiter's completed native launch supplies its original fully admitted
four-stage queue. The existing fifth-stage admission runs with full input
verification. The resulting queue must contain the same original batch and hold
waiter identities as the prospective prefix. Its negative results and prefix
findings are retained. Later bound verification calls the existing complete
queue verifier and repeats the raw-prefix checks without reexecuting the full
fifth-stage training-input reconstruction.

Source: `scripts/sustained_hold_reorientation_native_inputs_development.py`.
Tests: `lewm/tests/test_sustained_hold_reorientation_native_inputs_development.py`.
Source preparation can run while the original queue is live. Actual input
admission cannot. This module neither allocates a native scene nor selects an
independent-study policy. A native launcher must additionally bind its controller,
scene, model, runtime sources and resource envelope and call these checks before
creating its exclusive output and worker.
