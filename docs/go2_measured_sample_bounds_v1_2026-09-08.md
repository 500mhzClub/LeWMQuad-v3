# Recorded sample-bound and foot-sphere refinement V1

Read only the completed direct-039 commitment-pose and nominal-action native
recordings. Authenticate their complete artifacts and the latest nominal-action
readout/source closure before and after. Reconstruct every available visual
surface-memory update from original public RGB-D/body packets and restored exact
JSON identity tuples. Retain unavailable observations. Reproduce every original
candidate articulated-surface check exactly before comparing refinements.

Build a parallel monotone index keyed by the same 25-mm voxels. Within each key,
retain outward-rounded coordinate bounds enclosing ALL inserted measured points,
their total count, original first witness and latest contributing frame. Later
mixed returns expand bounds; no ground label, point deletion, eviction or ray
carving. Compare the original whole-voxel query with tight sample bounds. Then
apply exact sphere-versus-bound-box distance for URDF sphere primitives (feet);
other primitives retain their existing conservative axis-aligned box query.
Tangency remains a possible hit with 1e-12-m numerical allowance for sphere
distance. Record both refinement stages, original checks and current-posture
queries at every original forecast context. Neither stage changes actions.

These are nominal bounds of measured points, not uncertainty envelopes or
continuous terrain coverage. A removed voxel-volume overlap is not free-space
certification. Actual foot/terrain interaction may still require appropriate
contact semantics; this experiment grants no such permission and waives no veto.

Five analytic tests must pass. Inspect hardware, require 8 GiB available RAM
and 41 GiB artifact free space, with a 1-GiB output capacity. Benchmark the same
first 40 frames per case with one/two threads, require exact result equality and
choose the faster configuration. Preserve all failures in the exclusive attempt;
no native execution, training, retry, promotion or navigation qualification.
