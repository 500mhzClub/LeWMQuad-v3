# Conditional execution of the original independent comparison

This launcher connects the existing fixed 32-case study to the joined final
admission verifier and actual monitored staged driver. It does not approve
the current policy or its 3,000-tick budget. A changed policy/budget requires
a separately checked successor before consuming independent sensor data.

After all five diagnostic waiters finish, `prepare_input_bundle` authenticates
the completed population inputs and successive three-, four-, and five-stage
queue evidence. Persist its returned value exclusively at
`docs/go2_independent_round_trip_completed_input_bundle_v1.json`, then conduct
the actual final review using the complete evidence reconstructed by
`review_evidence`. Write the review separately at
`docs/go2_independent_round_trip_final_policy_review_v1.json` only if the decision
is to execute this exact original study. Both documents must be hash-bound in
the final source closure. Neither document exists merely because this source
has been prepared.

The CLI requires both exact document SHA-256 values. It authenticates the actual
source/input/queue/review evidence and bounded CPU overlap proofs before creating
an output, and the driver independently repeats its own mandatory checks.
`--source-preflight-only` needs no review, performs no full input admission,
loads no model and creates no output. `--preflight-only` performs complete
admission but creates no output or worker. Normal execution uses the exclusive
root `go2_independent_round_trip_population_v1_attempt_001`, retains every
failure, and never retries, resumes or substitutes layouts based on outcomes.

The roster remains eight independent development layouts by four matched arms,
in the original cyclic order. One native collector and one monitored CPU auditor
may overlap subject to the original registration barriers, predecessor-arm
acceptance, at most two unaccepted cases, at least 64 GiB available RAM, and the
complete remaining population storage allowance. Fresh processes isolate each
collection and audit. The original robot, renderer and sensor identities are
inherited from the fully authenticated adapter-batch launch.

An actual full native study would be simulation evidence with physics paused
during computation. The launcher and result retain no real-time, hardware,
navigation or overall-goal qualification. Scientific outcomes and causal claims
must be assessed from the completed full population and its recorded limitations.
